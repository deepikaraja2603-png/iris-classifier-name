# 🌸 Iris Flower Classifier — AI-Powered Mini App

**Module 5: AI Tools & Mini Project**

This project extends the machine learning model built in **Module 4** into a real, interactive
web application. Instead of just predicting on test data inside a notebook, this app lets anyone
enter flower measurements and get a live prediction, with confidence scores per species.

## What it does

- Loads a K-Nearest Neighbors model trained on the classic Iris dataset (~93% test accuracy)
- Provides a simple Streamlit UI with sliders for sepal/petal length and width
- Predicts the flower species and shows a confidence bar chart for all 3 possible species

## How AI tools were used in this project

As part of Module 5, this project was built with the help of AI assistants for:
- **Coding** — scaffolding the training script and Streamlit app structure, and debugging
- **Research** — understanding how to persist a scikit-learn model with `joblib` and load it
  efficiently inside a Streamlit app using caching
- **Productivity** — generating this README and project documentation quickly

## Project structure

```
iris-classifier-app/
├── train_model.py       # Trains the model and saves it to model/
├── app.py                # Streamlit app that loads the model and serves predictions
├── requirements.txt      # Python dependencies
├── model/                 # Saved model, scaler, and class names (generated by train_model.py)
└── README.md
```

## How to run it locally

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Train the model (creates the model/ folder)
python train_model.py

# 3. Launch the app
streamlit run app.py
```

The app will open in your browser at `http://localhost:8501`.

## Tech stack

- Python
- scikit-learn (model training)
- Streamlit (web app / UI)
- pandas / NumPy (data handling)

## Origin

This project builds directly on **Module 4: Machine Learning Fundamentals**, where the same
KNN classifier was first trained and evaluated in a Jupyter/Colab notebook. Module 5 turns that
